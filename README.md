# Fundación Raíces Unidas

Prototipo estático de una página de donaciones para una organización sin fines de lucro.

## Ejecución

Abrir `index.html` en un navegador. No requiere dependencias externas.

## Flujo colaborativo

- Rama principal: `main`.
- Nueva funcionalidad: `feature/pagina-donaciones`.
- Cada cambio se revisa mediante pull request antes de fusionarse.
- Las incidencias se registran en GitHub Issues con pasos para reproducirlas y criterio de cierre.
